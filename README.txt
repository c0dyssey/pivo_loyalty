ПРОГРАММА ЛОЯЛЬНОСТИ — ПИВНОЙ МАГАЗИН
=====================================
Правило: каждые 6 оплаченных литров ЛЮБОГО пива = 1 литр любого пива бесплатно (общий счёт клиента).
Какое пиво отдать в подарок, выбирает клиент; оно не обязано совпадать с купленным.
Литры разных напитков складываются в один счёт. По напиткам статистика ведётся отдельно (что куплено, чем отдан подарок).

ЗАПУСК (Windows)
1. Установите Python 3 с python.org (галочка "Add Python to PATH"). Больше ничего ставить не нужно.
2. Запустите start.bat. Окно не закрывайте: пока оно открыто, сайт работает.
3. ПЕРВЫЙ РАЗ откройте на самом ПК https://localhost:8443 и задайте PIN (один PIN на магазин).
4. СЕРТИФИКАТ, ОДИН РАЗ (чтобы не было предупреждений ни на ПК, ни на телефоне).
   Программа сама создаёт свой центр сертификации (data/cert/ca.crt) и выпускает им сертификат сайта.
   - Windows: запустите install-cert.bat (подтвердите окно "Да"), перезапустите браузер.
   - iPhone: откройте в Safari https://192.168.x.x:8443/ca.crt (адрес из окна программы; на этом шаге предупреждение
     ещё будет: «Показать подробности» -> «посетить веб-сайт») -> «Разрешить» -> Настройки -> «Профиль загружен» ->
     «Установить». Затем Настройки -> Основные -> Об этом устройстве -> Доверие сертификатам -> включите
     «Pivo Loyalty Local CA». Эти же шаги есть в разделе «Настройки» сайта.
   Сертификат сайта продлевается автоматически (при смене IP или за 30 дней до конца срока), переустанавливать ничего
   не нужно. Папку data/cert не удаляйте: ключ центра там; если удалить, ca.crt придётся поставить заново.
5. На телефоне (Wi-Fi магазина) откройте адрес "С ТЕЛЕФОНА" из окна: https://192.168.x.x:8443
   Работает ТОЛЬКО HTTPS на порту 8443. Обычного http (8080) нет. Камера для QR работает только по HTTPS.
6. Windows спросит про доступ в сеть: разрешите для "Частной сети".

НАПИТКИ — ФАЙЛ settings.json (открывать Блокнотом)
Каждый напиток — одна строка в списке "drinks":
  { "id": "weissburg-lager", "name": "Вайсбург Лагер", "emoji": "🍺", "color": "#d97706" },
- name  — название на плитке (обязательно)
- emoji — значок (необязательно, по умолчанию 🍺)
- color — цвет плитки #rrggbb (необязательно, подберётся сам)
- id    — внутренний код напитка, латиницей. ПО НЕМУ хранится история клиентов.
          Не меняйте id у существующих напитков! Название (name) менять можно свободно.
          У нового напитка id можно не писать: он создастся из названия.
- "active": false — спрятать напиток из продаж (накопленные клиентами литры сохранятся).
Можно писать просто строкой: "Новый сорт". Запятые между строками обязательны, последняя строка без запятой.
Сохранили файл — обновите страницу на телефоне. Если в файле ошибка, сайт покажет её в «Настройки» и
продолжит работать со старым списком.

КАК РАБОТАТЬ
- Поиск: последние цифры телефона или фамилия. Или кнопка «Сканировать QR» (камера внутри сайта).
- QR клиента содержит только его код (без имени, телефона и адреса сайта). Работает только в этой программе.
  Клиент сохраняет картинку QR в телефон. Не получилось отсканировать: кнопка «Сфотографировать QR» или поиск по номеру.
- На плитке каждого напитка у клиента: сколько литров он купил этого пива и сколько подарка им отдано (🎁). Счётчик «До подарка» общий.
- Покупка: плитка напитка -> объёмы (+0,5 / +1 / +1,5 / +2 / +3) -> «Подтвердить покупку».
  Когда общий счёт дошёл до 6 л — сразу предложение списать бесплатный литр (решает клиент).
- Списание подарка: список, как у покупки. Выберите пиво, нажимайте +0,5/+1/+1,5/+2 или «Весь остаток», добавьте другое пиво,
  затем «Подтвердить списание». В сумме не больше доступного. Одна операция может включать несколько разных напитков.
- Фамилия необязательна: достаточно имени и телефона.
- Список покупки внизу не перекрывает страницу: она прокручивается до конца истории.
- Отмена: кнопка «Отмена» у ЛЮБОЙ операции в истории, с подтверждением. Если отменяется покупка, из-за которой
  уже списан подарок, сайт покажет это в окне подтверждения и отменит и списание.
- Меню ☰: статистика магазина, «Все покупатели» (полная таблица по каждому клиенту), настройки.

ДАННЫЕ, НАДЁЖНОСТЬ И ВОССТАНОВЛЕНИЕ
- data/data.json — вся база (формат JSON). Каждая операция пишется сразу: временный файл -> fsync -> атомарная замена.
  data/data.json.prev — предыдущая версия (на одну операцию назад), страховка на случай сбоя диска.
- Повтор запроса безопасен: у каждой операции свой request_id, он хранится в базе (30 дней).
  Нажали «Подтвердить» второй раз после обрыва связи или перезапуска сервера — дубля не будет, сайт покажет
  «уже была записана». Один и тот же ID для другого запроса сервер отклоняет.
- data/backups/ — копия каждый день (хранится 30), каждая копия проверяется. Свежая копия за сегодня обновляется раз в час.
  Копию на второй носитель (флешка/другой диск) вы делаете сами: копируйте папку data целиком.
- При запуске база проверяется. Если файл повреждён: оригинал сохраняется в data/corrupt/, молчаливого отката
  НЕТ, сайт переходит в режим «только чтение», все изменяющие операции блокируются с понятной ошибкой.
  Восстановление: на ПК магазина откройте https://localhost:8443, введите PIN, выберите версию (.prev или копию)
  и подтвердите. Подтверждённые операции, которые есть в выбранной версии, сохраняются; сайт покажет, сколько операций
  и клиентов вернётся. Пустая база поверх повреждённой не создаётся никогда.
- data/events.log — журнал событий (запуск, ошибки записи, восстановления).
- Сайт доступен только в Wi-Fi магазина. Не пробрасывайте порт 8443 на роутере.
- Закрепите IP компьютера в роутере (резерв DHCP), иначе адрес для телефона изменится
  (сертификат привязан к IP; при смене IP он выпустится заново сам, доверие к центру сертификации сохраняется).
- Автозапуск: Win+R -> shell:startup -> положите ярлык на start.bat.
- Забыли PIN: удалите data/config.json и откройте сайт на ПК, задайте новый (клиенты сохранятся).
