ПРОГРАММА ЛОЯЛЬНОСТИ — ИНСТРУКЦИЯ
==================================

ПРОГРАММА И НАСТРОЙКИ
- На ноутбуке работает локальный HTTPS-сервер и хранится авторитетная база клиентов.
- GitHub Pages (папка docs/) публикует только клиентское PWA-приложение. Телефон подключается к API ноутбука по Wi-Fi.
- На ноутбуке https://localhost:8443 (порт по умолчанию) открывает отдельную панель управления сервером.
  Если задан другой HTTPS-порт, используйте его вместо 8443. Панель не предназначена для работы продавца с клиентами.
- В панели можно задать/изменить PIN, название приложения, список напитков, правило награды, настройки синхронизации
  и резервного копирования. Все изменения сохраняются в settings.json рядом с server.py и start.bat.
- Телефон использует клиентское приложение GitHub Pages; его настройки подключения и офлайн-работа находятся отдельно
  от панели ноутбука. В меню телефона «Настройки» остаются настройки приложения продавца, не серверная админ-панель.
- Если settings.json отсутствует, сервер создаёт файл с настройками по умолчанию. settings.example.json — шаблон
  начальной конфигурации, который при желании можно скопировать до запуска.
- PIN не хранится в settings.json. Он задаётся один раз и сохраняется на ноутбуке в data/config.json в виде хеша.
  Режим инкогнито не сбрасывает PIN. Если он показывает первичную настройку, сервер не нашёл data/config.json;
  проверьте, что запущен тот же экземпляр программы и используется та же папка data.

НАСТРОЙКА НА НОУТБУКЕ (WINDOWS)
1. Установите Python 3 с python.org, включив «Add Python to PATH».
2. Запустите start.bat и оставьте окно открытым.
3. На ноутбуке откройте https://localhost:8443. При первом запуске создайте PIN; он же используется на телефоне.
   При следующих запусках откроется вход. После входа появится панель управления сервером.
4. В панели задайте название программы, правило лояльности и список напитков; настройте HTTPS-порт, разрешённые
   Pages origins и политику резервного копирования. Используйте кнопку «Сохранить настройки».
5. Изменения магазина, напитков и правила лояльности применяются автоматически. Для изменения порта, Pages origins,
   расписания и хранения резервных копий перезапустите сервер. После изменения порта обновите адрес на телефоне.
6. Для смены PIN используйте раздел «PIN доступа» панели. PIN и настройки хранятся на ноутбуке, поэтому обычный
   браузер и режим инкогнито должны показывать один и тот же статус настройки. Если в инкогнито снова видна
   первичная настройка, не задавайте PIN повторно: проверьте, что запущен тот же сервер и используется та же папка data.
7. Для доступа телефона в Windows разрешите Python/start.bat в брандмауэре только для частной сети.
   Не пробрасывайте HTTPS-порт на роутере в интернет.

СТРУКТУРА settings.json
---------------------------
Панель создаёт и обновляет settings.json автоматически. Ниже приведён пример формата этого файла для диагностики
или начальной ручной настройки. Не редактируйте файл одновременно с открытой панелью.

{
  "shop": "Пивной магазин",
  "drinks": [
    { "id": "lager", "name": "Лагер", "emoji": "🍺", "color": "#d97706" },
    { "id": "blanche", "name": "Бланш", "emoji": "🍋", "color": "#f59e0b" },
    { "id": "seasonal", "name": "Сезонный сорт", "active": false }
  ],
  "loyalty": {
    "paid_liters": 6,
    "reward_liters": 1
  },
  "server": {
    "https_port": 8443,
    "pages_origins": [
      "https://c0dyssey.github.io"
    ]
  },
  "backups": {
    "interval_hours": 1,
    "retention_days": 30
  }
}

ПОЛЯ НАСТРОЕК
- shop — название магазина, до 60 символов.
- drinks — непустой список напитков. Для каждого:
  - id — латинские буквы, цифры, дефис или подчёркивание, до 40 символов. Не меняйте ID существующего напитка:
    история продаж привязана к этому значению.
  - name — название напитка, обязательно.
  - emoji — значок, необязательно (по умолчанию 🍺).
  - color — цвет плитки #RRGGBB, необязательно.
  - active — true/false; false скрывает напиток из продаж, не удаляя историю и накопленные литры.
- loyalty.paid_liters — сколько оплаченных литров любого напитка нужно для награды.
- loyalty.reward_liters — сколько литров любого напитка можно получить бесплатно.
  Оба значения должны быть положительными и кратными 0,5 л. Изменение правила пересчитает балансы по всей истории
  клиентов по новому правилу, поэтому согласуйте изменение и сначала сделайте резервную копию.
- server.https_port — HTTPS-порт от 1 до 65535. По умолчанию 8443. Изменение требует перезапустить сервер,
  после чего обновить адрес сервера на телефоне, если порт изменился.
- server.pages_origins — список точных HTTPS origins, которым разрешён доступ к API из браузера. Указывайте только
  origin, без пути и завершающего слеша. Для GitHub Pages проекта по умолчанию это https://c0dyssey.github.io.
  Не используйте "*". Изменение требует перезапустить сервер.
- backups.interval_hours — период проверки/создания автоматической копии, целое число 1–168.
- backups.retention_days — сколько последних копий хранить, целое число 1–3650. Изменение вступает в силу после
  перезапуска сервера.

При ошибке конфигурации панель покажет сообщение; сервер не сохранит неверные параметры. Для штатной настройки
используйте панель, а settings.example.json оставьте как шаблон.

СЕРТИФИКАТ HTTPS
1. После запуска откройте в браузере ноутбука https://localhost:8443.
2. Запустите install-cert.bat для доверия сертификату Windows.
3. На iPhone откройте в Safari https://<IP-НОУТБУКА>:8443/ca.crt. При первом подключении можно один раз принять
   предупреждение браузера, затем установите загруженный профиль: Настройки iOS → «Профиль загружен» → «Установить».
4. В Настройки → Основные → Об этом устройстве → Доверие сертификатам включите доверие к «Pivo Loyalty Local CA».
   IP-адрес ноутбука показан в окне сервера. Для стабильного IP закрепите адрес ноутбука в роутере.
Не удаляйте data/cert: там находится ключ центра сертификации. Смена/удаление этого ключа требует снова установить
новый CA на телефоне и Windows.

ПУБЛИКАЦИЯ PWA НА GITHUB PAGES
1. Изменяйте исходники приложения в static/.
2. Выполните `python build_pages.py`. Скрипт копирует только разрешённые публичные файлы в docs/ и отклоняет
   неожиданные или секретные файлы.
3. В GitHub выберите Settings → Pages → Deploy from a branch → ветка main → папка /docs.
4. Откройте https://c0dyssey.github.io/pivo_loyalty/ на iPhone. Разрешите локальную сеть, укажите HTTPS-адрес
   ноутбука из окна сервера и войдите по PIN.
Папка docs/ — собранная копия для Pages. Не редактируйте её вручную; после изменения static/ пересоберите docs/.

РАБОТА ПРОДАВЦА
- Поиск выполняется по номеру телефона или имени/фамилии. QR содержит только код клиента.
- Покупка: откройте клиента, выберите напиток и объём, подтвердите покупку.
- Награда рассчитывается от общего количества оплаченных литров всех напитков. Списание награды можно разделить
  между разными напитками.
- Изменение карточки клиента и отмена операции требуют подключения к серверу.
- На телефоне покупки, списания и регистрация клиента сначала сохраняются в IndexedDB вместе с очередью синхронизации.
  При связи с ноутбуком они отправляются на сервер; повторная отправка того же operation_id не создаёт дубликат.
- В меню ☰ доступны статистика, все клиенты и дополнительные серверные действия. При недоступности ноутбука
  приложение продолжает офлайн-работу с ранее загруженными данными и сохраняет очередь.

ДАННЫЕ И ВОССТАНОВЛЕНИЕ
- data/data.json — авторитетная база клиентов и операций; data/data.json.prev — предыдущая версия.
- data/config.json — хеш PIN и параметры защиты от подбора. Не редактируйте вручную.
- data/backups/ — проверенные резервные копии; data/cert/ — HTTPS-ключи и сертификаты; data/events.log — журнал.
- Не удаляйте data/ для обычного изменения магазина. Удаление этой папки уничтожит клиентскую базу, PIN, pairing,
  резервные копии и сертификаты. Для чистого начала удаляйте её только после явного решения владельца магазина.
- При повреждении базы сервер блокирует изменения и не создаёт пустую базу поверх повреждённой. Восстановление
  выполняется через локальную страницу на ноутбуке; сначала проверьте дату и число операций в выбранной копии.
- Офлайн-очередь телефона хранится отдельно от ноутбука. Не очищайте данные сайта/PWA и не переустанавливайте
  приложение, пока очередь не синхронизирована или не экспортирована через меню «Настройки».
